## 🌟 Overview

A modern, high-performance, futuristic portfolio website designed to showcase creative design, UI/UX case studies, branding posters, and motion graphic reels with interactive animations, dark mode aesthetics, and protected media showcases.

---

## ✨ Features

- **Futuristic Dark Cyberpunk Aesthetic**: Custom ambient glows, tech grid overlay, and high-contrast typography.
- **Custom Interactive Cursor**: Particle trailing canvas, interactive ring, and magnetic hover effects.
- **Interactive 3D Software Dock**: Glossy 3D squircles showcasing tools (Illustrator, Photoshop, InDesign, After Effects, Premiere Pro, Figma, JavaScript).
- **Categorized Portfolio Showcase**:
  - 🎨 **Graphic Design**: Posters, branding, social media creatives, print media.
  - 📱 **UI/UX Design**: Mobile app designs (KickOff, Cookies Pure) and web dashboards with interactive mockups.
  - 🎬 **Motion Graphics & Video Editing**: Commercial videos, travel reels, and kinetic typography.
- **Media Lightbox & Video Player**: Fullscreen modal view with protected media previews.
- **Experience & Education Timeline**: Chronological journey with detailed achievements.
- **Interactive Contact Form**: Direct channels for inquiries, socials, and resume download.
- **100% Responsive**: Fluid layout adaptable to mobile, tablet, and ultra-wide displays.

---

## 🛠️ Built With

- **Structure**: HTML5 (Semantic & Accessible)
- **Styling**: Vanilla CSS3 (Custom Properties, Flexbox, Grid, Glassmorphism, 3D Transforms)
- **Interactivity**: Vanilla JavaScript (Canvas particle physics, IntersectionObserver, modal controllers)
- **Icons**: FontAwesome 6 & Custom SVGs
- **Typography**: Space Grotesk, Syne, Outfit, Plus Jakarta Sans

## 🚀 Getting Started

### Local Preview

No complex build steps or dependencies required! You can run this project locally in any modern browser:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/RISH360/portfolio.git
   cd portfolio
   ```

2. **Open the project**:
   - Double click `index.html` to open it in your default browser, or
   - Use VS Code **Live Server** extension (`Right-click index.html -> Open with Live Server`).
